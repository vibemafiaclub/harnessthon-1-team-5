# Decision

의사결정 로그. 설계 과정에서 내린 판단과 근거를 기록한다.

## 형식

파일명: `NNN-제목.md` (예: `001-token-strategy.md`)

```markdown
# [제목]

- 일시: YYYY-MM-DD
- 상태: 제안 | 채택 | 폐기
- 참여: 이름, 이름

## 맥락
왜 이 결정이 필요했는가

## 선택지
1. A안 — 장점 / 단점
2. B안 — 장점 / 단점

## 결정
어떤 안을 선택했고, 그 이유

## 결과
이 결정으로 인해 변경된 것
```

## 언제 쓰는가

- 단계 분할이나 순서를 변경했을 때
- 컴포넌트 설계 방식을 결정했을 때
- 특정 PRD 해석에 팀 합의가 필요했을 때
- 기술적 제약으로 우회한 경우

## 참고

이 디렉토리의 활용 여부는 선택적이다. 다만 하네스 설계 완성도 심사에서
"협업의 흔적"으로 참조될 수 있다.
