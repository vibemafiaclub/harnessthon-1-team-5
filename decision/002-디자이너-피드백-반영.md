# 디자이너 피드백 리포트 v1.1 → 하네스 반영

- 일시: 2026-08-01
- 상태: 채택 (초안 빌드 완료, Penpot 실행 검증 전)
- 참여: 김민철

## 맥락

기존 당근 테스트 시안에 대해 디자이너가 준 피드백 리포트 v1.1에서
문제 3가지가 지적됐다.

| # | 문제 | 원인 |
|---|---|---|
| a | primary color가 너무 많이 쓰임 | 컬러 역할 정의 없이 "강조 = primary" 일괄 적용 |
| b | 이미지가 없어 빈 영역을 컬러 면으로 채움 | 일러스트 에셋 파이프라인 부재 |
| c | 각 로고가 단색 처리됨 | 브랜드 마크와 UI 아이콘을 같은 규칙으로 취급 |

이는 개별 시안의 실수가 아니라 **하네스에 규칙이 없어서 재발하는 문제**다.
그래서 시안을 고치지 않고 **단계별 지침으로 고정**한다.

## 그대로 쓰지 않고 번역한 것 (근거)

리포트는 **B2B 웹** 기준이고 우리 산출물은 **Penpot 모바일 앱 화면**이다.

1. **CSS 변수 → JS 상수.** `figma.variables.*`는 성공 응답만 오고 토큰이 거의 안 남는다.
   토큰은 `develop/scripts/tokens.js` 상수로 두고 `COLOR.*`로만 호출한다.
2. **WebP 2x·lazy·alt 삭제.** Penpot에 해당 개념이 없다.
   대신 `uploadMediaUrl` + 네이밍 규약 + `_sources.json` 기록으로 대체했다.
3. **3D 아이콘 생성 경로 변경.** 이 하네스에는 **이미지 생성 모델이 없다.**
   외부에서 뽑아 반입하는 흐름은 무인 실행이 안 되므로,
   Penpot 도형으로 조립하는 것을 주 경로로 두고 외부 반입을 폴백으로 내렸다.
4. **그레이스케일 검수 → 계산 검사.** Penpot에 그레이스케일 미리보기가 없다.
   `primaryAreaRatio` / `primaryElementCount` / `neutralStepsUsed`로 같은 것을 본다.
5. **기업 로고 수급 우선순위 조정.** 우리 과제는 `기존파일` Page가 1순위다.
   PRD에 근거 없는 실존 기업명은 가상 브랜드로 대체한다.

## 남은 확인

- **`color-audit.js`와 `empty-state-illust`의 코드는 실행 검증 전이다.**
  Penpot 필드명(`fills`, `children`, `board`/`frame` 타입)을 첫 실행에서 맞춰야 한다.
- 네이밍 규약(`btn/primary` 등)이 지켜져야 검증이 버튼을 셀 수 있다.
  ④와 ⑤가 같은 규약을 보고 있는지 팀에서 한 번 맞춘다.
- `decision/001` 의 **0번(산출물 경로 계약)** 은 여전히 조장 확정 대기다.
  현재 stage agent들은 기존 계약인 `docs/artifacts/`를 쓰도록 작성했다.
