# Policy

기능 단위, 스토리 단위의 디자인/구현 정책 문서 모음.

## 🔴 하네스는 이 디렉토리에 쓰지 않는다

`decision/001` 0번 결정 — **하네스가 쓰는 유일한 경로는 `docs/artifacts/`다.**

- ② 정책 단계의 산출물은 **`docs/artifacts/02-policy.md`** 다.
- 이 디렉토리는 **사람이 쓰는 문서**와, 리허설 결과를 비교용으로 남기는 **스냅샷** 자리다.

```
policy/
├── daangn/        ← 당근 PRD 리허설 결과 스냅샷 (수동 복사)
├── airbnb/        ← Airbnb PRD 리허설 결과 스냅샷 (수동 복사)
└── final/         ← 최종 심사용
```

두 스냅샷의 내용이 **서로 달라야 정상**이다. 같으면 ②가 PRD를 안 읽고 있다는 뜻이다.

## ②가 만드는 것 (`docs/artifacts/02-policy.md`)

`01-screens.md`의 화면 목록을 받아 화면별로 아래를 확정한다.

| 절 | 내용 |
|---|---|
| 화면 골격 상수 | 앱바 높이, 좌우 패딩, 하단 CTA 높이, 카드 간격 (4px 배수) |
| 컬러 예산 배정 | **화면당 primary CTA 정확히 1개** + 보조 행동 + accent 사용처 |
| 더미 데이터 | 리스트 화면당 8~12행. 길이가 제각각이어야 진짜로 보인다 |
| 숫자·단위 포맷 | 천단위 콤마, 증감 부호, 상대 시간, 말줄임 기준 |
| 상태 화면 문구 | 안내 문구 + 후속 버튼 라벨 1개 + 일러스트 컨셉 |

## 작성 원칙

- 하나의 정책 항목은 하나의 화면 또는 상태에 대응한다
- PRD의 유저 스토리에서 파생된 화면과 상태를 빠짐없이 커버한다
- **`Lorem ipsum`·"제목 1" 같은 자리표시 문구 금지.** 하나라도 보이면 완성도 점수가 무너진다
- **실존 기업·실존 인물명 금지.** PRD에 근거가 없으면 가상 이름을 만든다
- 당근과 Airbnb 둘 다에서 동작하는 범용 정책을 목표로 한다
