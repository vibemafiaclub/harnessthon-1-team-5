# Policy

기능 단위, 스토리 단위의 디자인/구현 정책 문서 모음.

## 구조

PRD별로 서브디렉토리를 만들어 관리한다.

```
policy/
├── daangn/        ← 당근마켓 PRD 기반 정책
├── airbnb/        ← Airbnb PRD 기반 정책
└── final/         ← 최종 심사용 PRD 기반 정책
```

## 문서 단위

각 디렉토리 안에서 기능 단위 또는 유저 스토리 단위로 정책을 나눈다.

| 예시 | 설명 |
|---|---|
| `home-feed.md` | 홈 피드 화면 — 레이아웃 규칙, 카드 구성 |
| `detail-view.md` | 상세 화면 — 진입 조건, 필수 요소 |
| `empty-state.md` | 빈 상태 — 문구, 아이콘, CTA |
| `filter-sort.md` | 필터/정렬 — 바텀시트 규칙 |

## 작성 원칙

- 하나의 정책 파일은 하나의 기능 또는 스토리에 대응한다
- PRD의 유저 스토리에서 파생된 화면과 상태를 빠짐없이 커버한다
- 당근과 Airbnb 둘 다에서 동작하는 범용 정책을 목표로 한다
