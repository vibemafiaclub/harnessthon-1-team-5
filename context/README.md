# Context

프로젝트의 배경, 타겟 유저, 목표를 정의하는 문서 모음.

## 🔴 현재 이 디렉토리를 채우는 단계가 없다 (미결)

`decision/001` 0번 결정으로 **하네스가 쓰는 경로는 `docs/artifacts/`로 확정**됐다.
그런데 아래 문서들을 만드는 단계는 파이프라인에 없다.

- ①은 `01-screens.md`(화면 목록)만 쓴다
- 나머지 단계도 이 디렉토리를 쓰지 않는다

**조장 결정 대기 항목이다.** 셋 중 하나를 골라야 한다.

1. ①에 배경 문서 생성을 붙인다 (①의 산출물이 2개가 된다 — 단계 분할 원칙에 어긋남)
2. 배경 문서 전용 단계를 추가한다 (단계가 늘어난다. 팀 sync 필요)
3. **이 디렉토리를 쓰지 않는다** — 화면 생성에 직접 기여하지 않으므로 오늘은 제외

시간이 없으면 3번이 합리적이다. 채점 축은 **화면 결과물**과 **하네스 설계**이지
배경 문서의 존재 자체가 아니다.
