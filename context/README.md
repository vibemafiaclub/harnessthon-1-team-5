# Context

프로젝트의 배경, 타겟 유저, 목표를 정의하는 문서 모음.

## 포함 문서

| 파일 | 설명 |
|---|---|
| `strategy.md` | 프로젝트 전략 — 비전, 미션, 핵심 가치 |
| `user.md` | 타겟 유저 정의 — 페르소나, 니즈, 행동 패턴 |
| `stakeholder.md` | 이해관계자 맵 — 역할, 기대, 커뮤니케이션 |
| `product.md` | 제품 정의 — 핵심 기능, 차별점, 성공 지표 |
| `architecture.md` | 시스템 아키텍처 — Mermaid 다이어그램 포함 |
| `workflow.mermaid` | 전체 워크플로우 — Mermaid 플로우차트 |

## 작성 원칙

- PRD를 입력으로 받아 각 문서를 자동 생성한다
- `architecture.md`는 반드시 Mermaid 다이어그램을 포함한다
- `workflow.mermaid`는 사용자 여정 기반 플로우를 정의한다
