# 일러스트 생성 프롬프트 기록

> 외부 이미지 모델로 뽑은 일러스트를 반입한 경우, **컷별 프롬프트 원문**을 여기 남긴다.
> 기록이 없으면 재생성이 불가능하고, 세트 일관성을 다시 맞출 수 없다.
>
> Penpot 도형으로 조립한 경우(주 경로)는 여기 적지 않는다.
> 조형 규칙은 `.claude/skills/empty-state-illust/SKILL.md`에 있다.

## 기록 형식

```
### illust/{state}
- 파일: illust-3d/{state}_2x.png
- 생성일: YYYY-MM-DD
- 모델: (사용한 이미지 모델)
- 프롬프트:
  > (원문 그대로. 줄바꿈 포함)
- 비고: accent 위치, 재생성 시 주의점
```

## 세트 일관성 규칙

같은 세트를 다시 뽑을 때 **각도·조명·재질·여백 구문은 바꾸지 않는다.**
바꾸는 것은 첫 줄의 subject와 accent 위치뿐이다.
한 세트는 같은 세션에서 연속 생성하고, 첫 컷을 레퍼런스로 삼는다.
