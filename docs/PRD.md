# PRD (입력 문서)

> 이 파일은 운영이 배포합니다.
> 개발 중에는 **예시 PRD**가, 심사 때는 **미공개 PRD**가 여기 들어옵니다.
>
> **하네스는 이 파일을 읽어 디자인을 만들어야 합니다.**
> 특정 PRD 내용에 맞춘 하드코딩은 심사용 PRD에서 그대로 무너집니다.

개발 중에는 [`docs/examples/`](./examples/)의 예시 PRD 2종을 이 파일에 복사해 쓰세요.

```bash
cp docs/examples/daangn-stock.md docs/PRD.md    # 당근마켓 → 증권
cp docs/examples/airbnb-dating.md docs/PRD.md   # Airbnb → 소개팅
```
