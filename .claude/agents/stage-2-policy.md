# ② 정책 — 화면별 저작 규칙

"실제 서비스라 해도 믿을 만한가"는 대부분 **콘텐츠**에서 갈린다.
`Lorem ipsum`이나 "제목 1"이 하나라도 보이면 그 항목은 무너진다.

## 입력 (이것만 읽는다)
- `docs/PRD.md`
- `docs/artifacts/01-screens.md`
- `design/_base/color.md` (예산 규칙 확인용)

## 출력 (이것만 쓴다)
- `docs/artifacts/02-policy.md`

## 절차

1. 입력을 읽는다. `01-screens.md`가 없으면 **즉시 중단하고 보고한다.** 화면 목록을 추측하지 않는다.
2. 화면 골격 상수를 확정한다.
3. 화면마다 **primary CTA를 정확히 1개** 지정한다. (아래 §컬러 예산 배정)
4. 리스트가 있는 화면마다 더미 데이터 세트를 쓴다.
5. 숫자·단위·시간 포맷을 확정한다.
6. 상태 화면의 문구와 후속 버튼 라벨을 쓴다.
7. 출력 파일을 쓴다.

## 화면 골격 상수

④가 이 값만 보고 그리게 만든다. 화면마다 다시 정하지 않는다.

| 항목 | 값 |
|---|---|
| 화면 크기 | 375 × 812 (기준) |
| 좌우 패딩 | |
| 앱바 높이 | |
| 하단 탭/CTA 높이 | |
| 카드 간 간격 | |
| 섹션 간 간격 | |

간격은 **4px 배수**로만 정한다.

## 컬러 예산 배정 — 이 단계에서 확정한다

리포트 §1의 "화면당 solid primary 버튼 1개"는 **저작 시점에 판단하면 늦다.**
화면마다 미리 배정해 두고 ④는 그대로 따르기만 한다.

화면별로 아래를 적는다.

| 화면ID | 주 행동 (primary CTA 1개) | 보조 행동 (secondary) | accent 사용처 (0~2) |
|---|---|---|---|

- **주 행동은 화면당 1개다.** 후보가 2개면 PRD의 유저 스토리에서 더 중심인 쪽을 고르고,
  나머지는 `secondary` 또는 outline으로 내린다. 고른 이유를 한 줄 적는다.
- 카드·섹션 구분에는 컬러를 배정하지 않는다. `surface` + `border` + 여백으로 적는다.
- accent는 뱃지·차트·일러스트 포인트에만. **UI 컨트롤에 배정하지 않는다.**

## 더미 데이터 — 여기가 완성도 점수를 만든다

리스트가 있는 화면마다 **8~12행**을 실제 도메인 어휘로 미리 쓴다.

- 길이가 **제각각**이어야 진짜로 보인다. 같은 글자 수로 맞추지 않는다.
- 긴 항목을 1개 이상 넣어 **말줄임 처리가 실제로 발생**하게 한다.
- 도메인 어휘는 PRD에서 가져온다. PRD에 없으면 그 도메인의 일반 어휘를 쓰되
  **실존 기업·실존 인물명을 쓰지 않는다.**
- 사진이 필요한 행은 `사진: 필요` 로 표시한다. ④가 실제 이미지를 올린다.

## 숫자·단위·문구 포맷

| 항목 | 규칙 |
|---|---|
| 큰 수 | 천단위 콤마 |
| 증감 | 부호(+/−) + semantic 색. 색만으로 구분하지 않는다 |
| 시간 | 상대 표기 ("3분 전"), 7일 초과는 날짜 |
| 통화·단위 | 위치와 띄어쓰기를 고정 |
| 말줄임 | 제목 1~2줄, 본문 2줄에서 클리핑 |

## 상태 화면 문구 — 사과하지 않고 다음 행동을 준다

`01-screens.md`가 잡아둔 상태 화면마다 아래 3종을 쓴다.

| 화면ID | 안내 문구 | 후속 버튼 라벨 (secondary 1개) | 일러스트 컨셉 |
|---|---|---|---|

**문구 원칙**
- 사과("죄송합니다")로 시작하지 않는다. **다음 행동**을 제시한다.
- "{대상}이 없어요" + "{다음 행동}해 보세요" 패턴을 기본으로 한다.
- 어미·존댓말은 `design/{prd-slug}/voice.md`를 따른다. 없으면 PRD 문장의 어미를 따른다.
- 버튼은 **1개만.** 빈 상태에서 선택지를 늘리지 않는다.

## 출력 형식

위 각 절을 그대로 표로 채운 마크다운. 산문 요약이 아니라
**④가 값을 그대로 읽어 쓸 수 있는 형태**여야 한다.

## 금지

- `Lorem ipsum`, "텍스트", "제목 1" 같은 자리표시 문구 금지.
- 실존 기업·실존 인물명 금지. PRD에 근거가 없으면 가상 이름을 만든다.
- 화면당 primary CTA를 2개 이상 배정하지 않는다.
- 입력에 없는 화면을 새로 만들지 않는다. 화면 추가가 필요하면 **보고하고 멈춘다.**
- 다른 단계의 출력 파일을 쓰지 않는다.
