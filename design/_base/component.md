# _base/component — 컴포넌트 환원 절차

> ⚠️ 절차 문서. 이 PRD의 컴포넌트 목록은 `docs/artifacts/03-design.md` §컴포넌트.
>
> **점수는 컴포넌트로 받는다.** 화면마다 같은 것을 다시 그리면
> 정렬이 어긋나고 수정이 전파되지 않는다.

## 1. 컴포넌트를 화면 목록에서 환원한다

지어내지 않는다. `docs/artifacts/01-screens.md`의 **필수 요소 칸에 2회 이상 등장하는 것**이
컴포넌트 후보다.

1. 화면별 필수 요소를 전부 나열한다
2. 같은 역할끼리 묶는다 (이름이 달라도 역할이 같으면 하나다)
3. **2회 이상 나오면 컴포넌트**, 1회면 그 화면에 직접 그린다
4. 1회지만 **상태 변형이 있으면** 컴포넌트로 만든다 (버튼·입력 필드 등)

## 2. 최소 세트 — 대부분의 모바일 PRD에서 나온다

아래는 체크리스트지 강제 목록이 아니다. **화면 목록에 근거가 있을 때만** 만든다.

| 컴포넌트 | 언제 필요한가 |
|---|---|
| `btn/primary` `btn/secondary` `btn/outline` | 행동이 있는 모든 화면 |
| `icon/{name}` | 아이콘이 쓰이는 곳 |
| `field/text` `field/search` | 입력·검색이 있을 때 |
| `card/{name}` | 목록 화면 |
| `chip/filter` | 필터·정렬 진입점 |
| `badge/{name}` | 상태 표시 |
| `appbar` `tabbar` | 화면 골격 |
| `sheet/bottom` | 바텀시트 |
| `illust/{state}` | 빈 상태 화면 |

## 3. 상태 변형 — `clone()`으로 만든다

컴포넌트마다 필요한 상태만 만든다. 전부 만들지 않는다.

| 상태 | 언제 |
|---|---|
| default | 항상 |
| pressed / selected | 탭·필터처럼 선택이 보이는 것 |
| disabled | 조건부로 막히는 행동이 PRD에 있을 때 |

**처음부터 다시 짓지 않는다.** `shape.clone()` → 덮을 것만 얹는다.

## 4. 🔴 이름은 처음에 확정한다

**만든 컴포넌트의 이름 변경·자식 remove는 플러그인을 멈춘다.**
잘못 만들었으면 고치지 말고 **새 이름으로 새로** 만든다.

- 네이밍 규약은 `_base/iconography.md` §4를 따른다
- **컴포넌트 이름은 파일 전역이다.** 옆 팀원 Page의 동명 컴포넌트가 잡힌다.
  찾을 때는 이름 + id 프리픽스로 좁힌다
- ⑤ 검증이 `btn/primary` 이름으로 버튼을 센다.
  **규약을 안 지키면 검증이 조용히 통과로 나온다** — 실패보다 위험하다

## 5. 규격은 토큰으로만 적는다

```
btn/primary
  height   : 48
  padding  : SPACE.lg (좌우)
  radius   : RADIUS.md   ← 전 화면 통일
  fill     : COLOR.primary
  label    : TYPE.label / COLOR.bg
```

raw 값(px·hex)을 직접 적지 않는다. 토큰 이름으로 적는다.
`docs/artifacts/03-design.md` §컴포넌트에는 이 형식으로 컴포넌트별 규격을 채운다.

## 6. 인스턴스에서 되는 것 / 안 되는 것

| 항목 | 가능 여부 |
|---|---|
| `characters` (텍스트) 오버라이드 | **된다** — 데이터가 다른 행은 인스턴스 재사용 |
| penpot 형식 `fills` 오버라이드 | **된다** (`{fillColor, fillOpacity}`) |
| figma 형식 `fills` | **막힌다** |
| 자식 추가·삭제 | 하지 않는다 |

가변 텍스트 칸은 **고정 폭 + 텍스트 정렬**로 만든다.
hug(자동 폭)로 두면 텍스트를 갈아끼워도 위치가 안 따라온다.

## 금지

- 화면 목록에 근거 없는 컴포넌트 생성
- 만든 뒤 이름 변경·자식 remove
- 규격에 raw 값 직접 기입
- 같은 역할인데 화면마다 다른 컴포넌트를 만드는 것
